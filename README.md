# Anup Dash portfolio

Extract this ZIP into a folder. Open index.html, or run `python3 -m http.server 4173` in that folder and visit http://127.0.0.1:4173/.

For hosting, upload the extracted files to a static website host, keeping assets/ beside index.html. No build step is required.

Includes a responsive homepage, four case studies, a printable résumé, the supplied CV as a text download, project filters, mobile navigation, and email/phone links.

Content is based on the supplied October 2026 CV and the user's earlier local portfolio materials. Review the reused project summaries before making the site public. A verified LinkedIn URL has not yet been supplied.

Edit index.html for the homepage, the four named case-study HTML files for projects, styles.css and case.css for design, and resume.html for the CV. Fonts load from Google Fonts with local system fallbacks.

Palette: deep teal #23514C, saturated teal #1F9B90, soft teal #98D2C9, warm teal #36B399, and warm off-white.

## Publish on GitHub Pages

1. Create a public GitHub repository. For a personal homepage, name it YOUR-USERNAME.github.io.
2. Extract this ZIP and upload its contents, keeping index.html and assets at the repository root. Include the empty .nojekyll file.
3. Open repository Settings > Pages. Set Source to Deploy from a branch, select main and /(root), and save.
4. When deployment finishes, use the Visit site link on that settings page.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
